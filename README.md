# FairRyde

Rule base, ground truth and validation for the FairRyde dispute agent (Tencent Cloud x AI Singapore hackathon 2026, Ryde track). Private repository.

- `CLAUDE.md`: project context and the rules every session follows
- `kb/`: knowledge base v0.1 and its build (`python3 kb/build_kb.py`)
- `validation/`: validation pipeline and round 1 results (NO-GO, see `validation/V5_scorecard/`)
- `docs/NEXT_STEPS.md`: plan for v0.2 and validation round 2
- `docs/DATA_INVENTORY.md`: inventory of every raw source and every processed data set, with counts and gaps (in Chinese)
